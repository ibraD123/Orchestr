# Basira как приложение в магазине приложений Salla

Статус: идея, сохранена 2026-11-06. Делать после первых пилотов с агентствами (см. «Кому продаём» в `ROADMAP.md`). Ничего из описанного ниже ещё не построено.

## Что это

Salla (سلة) — саудовский конструктор интернет-магазинов, местный аналог Shopify. У него есть магазин приложений (apps.salla.sa): продавец открывает его в своём кабинете и ставит приложение в один клик. Разработчики выкладывают приложения через портал Salla Partners (salla.partners).

Идея: выложить туда Basira. Владелец бренда находит нас внутри Salla, ставит, и Basira сама получает его каталог, проверяет карточки и записывает одобренные исправления обратно в магазин.

## Зачем

- **Дешёвый канал к владельцам брендов.** Они ищут инструменты прямо в магазине приложений Salla, не нужно продавать каждому вручную. Salla Partners пишет о 68 000+ активных магазинов, документация API — о 60 000+. Store Leads в нашем прошлом исследовании насчитал 26 385 магазинов (по своей методике).
- **Доверие.** Установка из официального магазина с отзывами и рейтингом.
- **Ниже порог входа.** Не нужны ссылки, CSV, регистрация и отдельный пароль.
- **Запись обратно в магазин.** Сейчас по Salla мы отдаём файл, который продавец загружает сам. Через API исправления применяются сразу.
- **Конкуренты рядом.** В магазине уже есть категории «الذكاء الاصطناعي» (ИИ) и «تحسين الموقع» (улучшение магазина), приложения стоят 20–99 SAR в месяц с бесплатным пробным периодом. Под наш продукт там есть место.

## Как это выглядит для продавца

1. В магазине приложений Salla — «Basira: проверка и улучшение карточек на арабском и английском», цена в SAR в месяц, бесплатный пробный период.
2. «Установить» → Salla спрашивает разрешение на доступ к товарам и отзывам → продавец соглашается.
3. Basira открывается уже с его каталогом: оценка каждой карточки, что исправить первым, правила бренда (Brand DNA).
4. Продавец смотрит исправления (тексты, слайды, главное фото), одобряет.
5. Одобренное записывается в магазин через API. Ничего не меняется без одобрения.
6. Новые товары и отзывы приходят сами (уведомления Salla), аудит обновляется.

## Как это устроено технически (по документации Salla, проверено 2026-11-06)

- **Доступ:** OAuth 2.0. Рекомендуемый Easy Mode: после установки Salla сама присылает на наш адрес уведомление `app.store.authorize` с токеном доступа и токеном обновления. Токен живёт 2 недели, обновляется через `https://accounts.salla.sa/oauth2/token`. Ссылка установки: `https://s.salla.sa/apps/install/{app-id}`.
- **Права (scopes):** выбираются в портале: товары, отзывы, уведомления. Нам нужны чтение и запись товаров, чтение отзывов, уведомления.
- **API продавца:** `https://api.salla.dev/admin/v2`. Нужные разделы: Products, Product Images, Product Options/Variants, Categories, Brands, Reviews, SEO.
- **Уведомления (webhooks):** `product.created`, `product.updated`, `review.added`; события приложения: установлено, пробный период начался и закончился, подписка началась, закончилась, продлена. Если наш сервер не ответил, Salla повторяет 3 раза примерно через 5 минут. Подпись проверяется секретом из настроек приложения.
- **Тестирование:** в портале создаются демо-магазины, приложение ставится туда до публикации.
- **Публикация:** шесть разделов анкеты: основная информация, настройки, возможности, цены, контакты, пробный период. Тарифы задаются в портале (есть и «Custom Plans»).

## Что нужно сделать у нас

1. Аккаунт в Salla Partners, приложение, демо-магазин.
2. Коннектор `server/connectors/salla.mjs`: OAuth (Easy Mode), хранение и обновление токенов по магазину, чтение товаров, фото и отзывов, запись заголовков, описаний и фото.
3. Связь с аккаунтами: один магазин Salla = один аккаунт Basira типа «бренд» (режим «один бренд» уже есть). Вход через Salla вместо пароля для таких аккаунтов.
4. Обработчик уведомлений Salla: установка, удаление, подписка, новые товары и отзывы.
5. Оплата: подписка через Salla вместо Moyasar для этих аккаунтов, синхронизация тарифа с событиями подписки.
6. Хранение каталога на сервере (сейчас каталог живёт в браузере; для приложения это обязательно).
7. Снимок карточки до записи и откат.
8. Описание и скриншоты для страницы приложения на арабском и английском.

Ценник рынка — 19–149 SAR в месяц, поэтому вход для приложения Basira в Salla должен быть в этом диапазоне, а слайды и отчёт — в тарифах выше. Подробно: [`research/landscape-2026-11.md`](research/landscape-2026-11.md).

## Открытые вопросы (уточнить в Salla Partners)

- Комиссия Salla с подписок и сроки выплат: на открытых страницах цифр не нашли.
- Сколько длится проверка приложения перед публикацией и какие требования к нему.
- Можно ли загружать фото через API файлом или только ссылкой (влияет на хостинг слайдов).
- Ограничения частоты запросов (в документации есть раздел Rate Limiting).
- Требования к хранению данных продавцов (PDPL, сервер в Саудовской Аравии).

## Другие платформы (после Salla)

Общий план и очередь — в `ROADMAP.md`, раздел «Магазины приложений платформ».

- **Zid App Market.** По данным Zid, 13 500+ активных магазинов. Путь: партнёрский аккаунт и договор, разработка и проверка на тестовом магазине, проверка Zid, публикация. Приложения бывают публичные (для всех магазинов) и частные (для одного). Zid платит партнёрам раз в месяц за вычетом своей доли; партнёрам не из Саудовской Аравии удерживают 15% налога. Отдельного ИИ-приложения для описаний в Zid на 2026-11-07 не нашёл.
- **Amazon Selling Partner Appstore.** Листинг — последний шаг для публичного приложения SP-API: нужна публичная регистрация разработчика, рабочая авторизация, соблюдение политик и проверка листинга (3–4 недели по документации). Без листинга публичное приложение могут подключить не больше 25 продавцов. Делать вместе с проверкой публикации на Amazon вживую.
- **Shopify App Store.** Не делаем: Shopify убран из продукта 2026-11-08, в регионе он меньше Salla и Zid.
- **Noon.** Магазина приложений нет. Есть Partner API: проверить, дают ли к нему доступ сторонним сервисам.

## Что уже есть в Basira и пригодится

- Аккаунты, режим «один бренд», тарифы и учёт использования.
