# Юридические документы: черновики

**Статус: черновики, не для подписания.** Их составил не юрист. Перед первым платным клиентом их должен проверить юрист с лицензией в Саудовской Аравии, а затем нужно подготовить арабские версии.

| Файл | Что это | Кто подписывает |
| --- | --- | --- |
| [`terms.md`](terms.md) | Условия сервиса (договор подписки) | Агентство, при оформлении тарифа |
| [`dpa.md`](dpa.md) | Соглашение об обработке данных (DPA) по саудовскому закону о защите персональных данных (PDPL) | Агентство, вместе с условиями |
| [`privacy.md`](privacy.md) | Политика конфиденциальности сайта и приложения | Публикуется на сайте |

## Что юристу проверить в первую очередь

1. **Роли по PDPL.** Агентство (и бренд, для которого оно работает) — контролёр данных, Basira — обработчик. Для заявок с сайта и данных аккаунта Basira сама контролёр. Подходит ли такая схема, если агентство само обрабатывает данные бренда по его поручению.
2. **Передача за пределы Саудовской Аравии.** Тексты и изображения уходят в Claude (Anthropic, США), хостинг может быть вне королевства, генератор фото ещё не выбран. Нужно основание для передачи по правилам о передаче данных за рубеж и, возможно, хостинг в саудовском регионе для клиентов, которым это нужно.
3. **Уведомление об утечке:** сроки и порядок уведомления регулятора (SDAIA) и клиентов.
4. **Применимое право и споры:** суды Саудовской Аравии или арбитраж (SCCA), язык договора (обычно при расхождении действует арабский текст).
5. **Оплата:** возвраты, автопродление (сейчас его нет: каждый месяц оплачивается отдельным счётом Moyasar), НДС 15 % и электронные счета ZATCA (FATOORA).
6. **Ограничение ответственности** за тексты и изображения, созданные ИИ, и за изменения карточек на площадках.
7. **Согласие на обезличенное использование** для улучшения моделей (в продукте выключено по умолчанию, включается по каждому клиенту в «Настройках»).

## Что уже есть в продукте для этих документов

- Выгрузка всех данных клиента и удаление клиента со всеми выгрузками: «Настройки → Данные клиентов» (`GET /api/workspaces/:ws/export`, `DELETE /api/workspaces/:ws`).
- Согласие на обезличенное использование по каждому клиенту, с датой (`PATCH /api/workspaces/:ws`).
- Ничего не публикуется на площадки без одобрения человеком.
- Учёт использования по тарифу и оплата по счёту Moyasar в SAR с НДС.

Чего нет: аккаунтов пользователей и авторизации (один сервер = одно агентство), журнала доступа, автоматического удаления по сроку хранения.
